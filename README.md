# Hospital Resource & Patient Management System

## Python Programming Project — Phase III

### Project Description

The Hospital Resource & Patient Management System is a Python-based console application designed to manage basic hospital operations, patient records, doctor details, appointments, room allocation, medical resources, billing, and treatment history.

The project demonstrates the use of fundamental Python programming concepts to organize and manage hospital-related information through a menu-driven interface.

### Features

- Add and view patient records
- Add and view doctor records
- Book and view appointments
- Add, allocate, release, and view hospital rooms
- Add and manage medical resources
- Create and view bills
- Maintain patient treatment history
- Generate a hospital resource status report
- Validate patient age and medical resource quantities
- Handle invalid numeric input in medical resource operations

### Technologies Used

- Python 3
- Lists and Dictionaries
- Functions
- Conditional Statements
- Loops
- Exception Handling
- Git and GitHub

### How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python hospital_management.py
```

5. Select an option from the menu and follow the instructions displayed by the application.

### Testing

The application has been tested for core operations, including patient registration, duplicate patient ID handling, invalid patient age, medical resource quantity validation, and resource usage.

Additional functional testing can be performed for doctor management, appointments, room allocation, billing, and treatment history.

### Limitations

- The application uses in-memory data structures, so records are not retained after the program exits.
- The application uses a command-line interface rather than a graphical user interface.
- The project is intended as an academic prototype and is not a production hospital management system.
