# Hospital Resource & Patient Management System

## Python Programming Language - Phase II

### Project Description
The Hospital Resource & Patient Management System is a Python-based console application designed to manage basic hospital operations and resources efficiently.

### Features
- Patient record management
- Doctor record management
- Appointment booking
- Room allocation and release
- Medical resource management
- Billing
- Treatment history
- Hospital resource status report

### Technologies Used
- Python
- Dictionaries
- Lists
- Functions
- Conditional Statements
- Loops

### Phase II Progress
A working Python prototype has been implemented and tested successfully.
